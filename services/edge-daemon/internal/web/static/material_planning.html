Checks for usable fabric

  1. Exact fabric specification + claimed GSM tolerance
  2. Shade delta-E versus claimed limit
  3. Usable inspected width ≥ claimed CAD marker width
  4. Inspection status ACCEPTED_PASS
  5. Stock age within submitted policy limit
  6. Buyer escrow/ownership compatibility and no other-PO hold

Every limit and status is an input assertion, not proof of buyer approval. Unknown or failed checks cannot reduce the net indent.
